# Order Billing Service (`v1.1.0`)

Сервіс розрахунку вартості доставки та формування рахунків-фактур, рефакторений відповідно до принципів слабкої зв'язності (**Data Coupling**).

## Архітектурні покращення
- **Усунено Common Coupling:** видалено глобальну змінну стану `GLOBAL_TAX_RATE`, ставку податку передано явним параметром `tax_rate` (за замовчуванням `0.20`).
- **Усунено Stamp Coupling:** функція `calculate_delivery_cost` приймає лише рядок `city` та вагу `weight_kg` замість усього об'єкта `CustomerProfile`.
- **Усунено Control Coupling:** прапорець `mode_flag` замінено на спеціалізовані функції `process_standard_invoice` та `process_tax_exempt_invoice`.

## Тарифи доставки
- **Ivano-Frankivsk:** базова ставка `50.0` + `15.0` за 1 кг
- **Kyiv:** базова ставка `80.0` + `15.0` за 1 кг
- **Інші міста:** базова ставка `110.0` + `15.0` за 1 кг
